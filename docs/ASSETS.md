## 清晰度与资源预算

- **禁止降分辨率**：公开展示用三张高清画卷必须保持原幅像素，人物必须保留原始非透明有效像素。
- 默认采用 WebP lossless（逐像素无损），非低质量 lossy WebP。不使用数十 KB 的预览冒充作品。
- 整套运行图片预计约 10MB，适合展示级网站，但弱网加载相对较慢，需显示加载状态。
- 后续若背景扩展到更多场景：可以用单独发布产物、CDN 或 Git LFS 分离源稿与运行资源；无须以 `git push -f` 反复改写 Git 历史。**`push -f` 本身并不会自动压缩已有提交历史**。
- 原稿继续保存在用户项目素材库，仓库中 `public/art/` 提交的是和原稿像素等价的无损展示文件。

## 画卷坐标与分层策略

画卷中四处观景点的世界坐标约为 X=172 / 793 / 1326 / 1837；坐标基于 2172×724 画布人工审看，尚需美术复核。人物移动使用临时的岸线/桥面节点高度曲线（`src/engine/ScrollEngine.ts`），与真实的遮挡层和路面高差分离。

**注意：** 三张 PNG 都是扁平化全景图（山、塔、桥、水面烘焙在单图内），因此目前不能实现建筑物正确遮挡人物，也无法独立扭曲原水面而不损坏美术。正式版应向美术方取得带 alpha 的前景桥栏、人物行走层、环境粒子图，而不是借代码或裁剪伪造精细层次。
