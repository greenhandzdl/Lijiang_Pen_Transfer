# ADR-0001：PixiJS 8 + TypeScript + Vite + React

- 日期：2026-11-12
- 状态：已采纳

## 背景
目标是青绿山水绘画式 2.5D 长卷，而非重物理 3D 游戏。原生 JS + 手写 Canvas 能实现，但长期绘图缓存、事件管理和 Sprite 场景维护成本偏高。

## 决定
- PixiJS 8 承担画卷、角色、Canvas/WebGL 渲染、图层、纹理与互动输入。
- TypeScript 严格模式负责架构边界与数据模型。
- Vite 负责开发 HMR、静态打包及 GitHub Pages base。
- React 仅负责按钮、对话、首页、设置等 DOM UI，不驱动每帧场景。

## 原因
PixiJS 活跃且适合遮挡/纹理/水面特效；游戏事件在领域层实现，不为单个演示直接引入重量级游戏引擎。开发体验优于完全原生方案。

## 代价
仍需自建路线/状态机/叙事配置；没有开箱即用的真实桥面落脚、动画补帧及文化文案审查。

## 限制
不复制 qingming-riverside 源码；不得将仅有一个姿态的图片宣称为完整步态动画。
