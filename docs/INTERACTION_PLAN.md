# M3 时辰叙事交互实施计划（2026-11-12）

> **状态说明：** P0 可点击骨架 / 状态同步 / Pixi 概念特效先行，完成级动画、美术、真实音乐联动和文化考据在 P1–P3。产品是高清艺术展演，不以临时特效覆盖原有画面。

## 已有资源与时辰映射

- 三张背景全都保留 **2172 × 724 无损 WebP** 原幅，五个姿态也保持有效像素原尺寸。
- 新的体验时段是 **清晨、正午、夕照、入夜**；底图对应 **day、day、dusk、night**。清晨和正午共享现有白昼原画，区别在互动内容。之后如果新增晨光独立原画，只修改数据映射，不在此阶段伪造光照。
- 昼夜与人物位置、时间段热点、剧情状态应通过 TS 数据统一管理；不得依赖每帧 React re-render。
- 分区交互以透明 Pixi 热区 + React 对话/控制面板实现；按钮必须可用键盘操作，可退出。

## 交互一：清晨渔人整理竹筏

**M3.1：** 在岸线添加可点击「渔人」热点；点击后停止/挂起当前引导行走，弹出问路对话；支持「象鼻山怎么走？」「竹筏何时可出发？」与关闭，包含艺术路线和非实地导航说明。

**M3.2（资源到位后）：** 角色 Sprite/Atlas 取代热点，至少 `idle / sorting-raft / talk / pointing / returning` 五状态；竹筏绳索、竹篙、水面交互及距离检测；靠近 NPC 才能激活。对话/靠近后播放的动作可中止，切换时辰必须复位。

- 美术：渔人角色一致风格透明 PNG/Atlas；竹筏及船篙单独前后层；岸边遮挡 alpha/mask。
- 验收：移动端和键盘能触发；重复点击不叠加对话；离开/切换时段退出；脚底贴合岸线。

## 交互二：正午鸬鹚捕鱼 + 岸边买鱼

**M3.1：** 两个独立热点「鸬鹚捕鱼」「鱼市」，分别能触发水纹反馈、文字说明和一段模拟购买对话，不接收支付或虚构真实鱼价。

**M3.3（资源到位后）：** 鸬鹚 `surface / dive / underwater / catch / return / rest` 动作序列，渔民与水面捕鱼同步；鱼摊 `waiting / ask / select / exchange / complete` 状态机，可取消。捕鱼行为按经审核的文化/生态资料描述。

- 美术：鸬鹚逐帧图、渔人/鱼篓/竹筏、单独水面波纹与 splash 层、鱼摊/挑选道具、NPC 对话头像。
- 验收：至少可重复完整捕鱼循环 2 次，脚底/水面遮挡正常；购买无真实支付，重进场景恢复预期。

## 交互三：夜间江上表演

**M3.1 功能骨架：**
- **岸边／船上**视角选择：保持原高清场景，切换镜头观察方式和角色位置提示；船舷/船体尚未有正式美术。
- **沿江分段亮灯**：按区域顺序渐亮，支持关闭、重播。应叠在原来的夜景灯光之上，绝不替换原夜景画作。
- **音乐与水中倒影**：提供明确标注的「无音频节奏预览」，波纹亮度受可控能量值驱动；加入 `setAudioEnergy` 接口以便正式版接 Web Audio AnalyserNode。
- **对山歌**：触发已有角色演示姿态、显示可关闭字幕/提示，默认没有音频。不使用任何未授权歌曲或未验证的民歌歌词。
- **无人机效果**：透明图层上的少量光点概念演示，提供开/关、减少动态效果适配。**不宣称现实活动中一定有无人机演出**。

**M3.4（完整功能）：** 岸边与船上分开设计镜头轨迹；夜景建筑灯具独立图层与分段遮罩；船只摇摆和船内人物走位；原创授权的山歌分句/对歌互动；音乐 FFT/beat envelope 以 `AnalyserNode` 获取能量驱动多个反射簇；无人机真实编队路径/粒子 GPU 实现、时间轴、淡出和无闪烁安全模式。

- 资源：船体/船内外多视角透明图与水面遮挡 mask、桥和塔楼灯光分层、对应区域反射图、夜景单独远山蒙层、授权的歌曲与歌词字幕、无人机路径数据。
- 验收：三段以上灯光按顺序点亮；音乐起伏能对应倒影且与音频时间轴对齐，暂停/静音一致；船视角手势操作仍可用；无人机能跳过、关闭、降低闪烁；在无音乐时无伪装的「音乐同步」宣传。

## 架构要求

```text
src/content/places.ts       时段与底图映射（morning/noon/dusk/night）
src/content/encounters.ts   可复用互动 ID、热区、对话/选择数据
src/app/App.tsx             HUD、对话、事件按钮、时辰与视角状态
src/app/ScrollStage.tsx     转发 React 状态和 Pixi onEncounter 回调
src/engine/ScrollEngine.ts  绘画/人物/热区与演出图层、帧内表现、接口
```

交互状态机需要在完成级实现时拆分为 `src/engine/events`，避免演出逻辑永久膨胀在 ScrollEngine 中。夜景渲染对象必须可销毁；事件不得播放未获授权音频；`prefers-reduced-motion` 下所有特效都要可静态显示或关闭。建议将图层各类能量值限制到 0–1 避免闪光刺激。
