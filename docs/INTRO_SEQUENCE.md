# 象鼻山 Three.js 序章与卷尾 · 分镜及验收说明

> 2026-11-13 | 场景性质：山水意象演绎，不是景区测绘、开放航线或真实水月洞通行许可的展示。

## 1. 为什么保留 PixiJS

主长卷（2172×724、清昼/夕照/夜景三幅原幅无损 WebP）必须持续以 PixiJS 展示。**Three.js 仅用于入画前与卷尾后的独立过场**，绝不将原绘画拆成伪 3D，也不改变下载压缩率或美术层级。

架构：

- 首页点击「入画启程」→ 按时辰懒加载 \`ElephantIntro.tsx\` → \`ElephantIntroScene.ts\` 创建 WebGL → 自动完成后进入原有 \`ScrollStage\`。
- 首页点击「山水漫游」→ 原有 Pixi 长卷（不强制看序章）。
- 第四景「玻璃桥」的地点签 → 「卷尾 · 回望象山题诗」→ 3D 回望镜头，停留在诗词画面；可返回画卷或回到卷首。
- 长卷顶部「重看象山序章 ↻」→ 不重置绘画美术，只重播演绎。
- 三维层代码通过 React \`lazy()\` / \`import()\` 懒加载，避免首页和直接漫游路径先下载 Three.js。

## 2. 入口分镜（约 15.2 秒）

| 段落 | 画面与动线 | 交互/字幕 | 技术实现 |
|---|---|---|---|
| 0～4.1s 环山观景 | 从江边侧逆向绕至水月洞正面，露出青绿石壁、洞口、江面 | 「象山回望」 | Camera 球面绕行、定向 LookAt |
| 4.1～8.8s 舟出水月 | 小舟由山体背后经**可视贯通的洞**驶向江面 | 「舟出水月」 | \`Shape.holes\` + \`ExtrudeGeometry\` / 曲线寻路 |
| 8.8～12.9s 临岸拾级 | 小舟曲线靠右侧阶岸，取向随航向转动；人物由舟中走上台阶 | 「临岸拾级」 | \`CatmullRomCurve3\` / easing / 角色脚底锚点 |
| 12.9～15.2s 山水入画 | 镜头渐近岸上旅人，短暂停留古诗，再衔接到象鼻山长卷第一景 | 「人已入画」／《水月洞》 | UI overlay＋过渡到 Pixi |

时间用于感受节奏，并不是实际船舶速度和导航路径。自然岩洞中的船只穿行是叙事性**艺术虚构**，不要在老师汇报时称为现实允许的旅游活动。

## 3. 卷尾分镜（约 9 秒后保持画面）

由「玻璃桥」手动触发：镜头从码头侧向象鼻山环望，画面停在「象山水月」的全山构图，并呈现：

> 水底有明月，水上明月浮。
> 水流月不去，月去水还流。

属于流传的《水月洞》诗句；署名在公开资料中并不完全一致，当前页面不做未经核实的个人署名。进一步校订时可引用中国天气网对水月洞与诗句的介绍：https://www.weather.com.cn/guangxi/sjgx/gxlytq/348008.shtml 。也可改为经导师审定的象山题刻、诗词或原创结尾文案。

## 4. 美术与性能边界

- 程序建模（Three.js \`ExtrudeGeometry\`、\`InstancedMesh\`）完成山体、真实洞口、山顶树冠、远山、江水 shader、轻量游船、石阶与角色；均无新增低清图片。
- 人物沿用原有 \`hero-front.webp\`，无丢失原图分辨率。船中与下船为**一张立绘的运动过渡**，不是逐帧骨骼动画或完整抬腿/接地 IK。
- 资源加载错误或 WebGL 不可用时保留「直接入画」出口；Esc 可跳过序章；减少动画偏好下入口直接跳转，卷尾提供静止的题诗画面。
- 桌面 DPR 上限 1.8，窄屏上限 1.35，优先保主长卷原画表现，Three.js 只在本段呈现且离场清理 WebGL 资源。
- 时辰进入前即由原有 \`morning/noon/dusk/night\` 决定三维天空与光照；主长卷仍只使用原有三幅高画质独立原画。
- 夜间不会自动播放录音；原创器乐仍需用户在 Pixi 夜景场景中主动点击。

## 5. 验收清单

1. **入口**：首页「入画启程」播放 Three.js；「山水漫游」跳过 3D，直接打开 Pixi。
2. **几何**：环绕时洞口具有可视通透的前后关系，而不是石壁上的贴图；游船依次穿洞、靠岸、人物登阶。
3. **可达性**：Esc／跳过序章可用；点击时辰后入画，三个独立长卷无损纹理仍正确显示。
4. **卷尾**：第四景地点签出现「卷尾 · 回望象山题诗」；回望镜头停在象山与诗句；「返回画卷」回原第四景，「回到卷首」回首页。
5. **设备**：手机竖屏、横屏旋转、Chrome / Safari WebGL、低性能设备 / WebGL 禁用、\`prefers-reduced-motion\`。
6. **质量门槛**：\`npm run typecheck && npm test && npm run build\`；Pages Actions 的产物部署、HTML+JS+原画资源 HTTP smoke test 成功；正式交付仍需人工视觉与交互验收。

## 6. 仍需美术/专业资料

正式版应以摄影测量/授权模型或分层绘画建立更接近真实地形的象鼻山及水月洞，核实码头位置与台阶路线。若需要严格拟真“人从船上下来”，请提供船体分层、行走关键帧（至少 6–8 帧）和台阶前景遮挡。当前是有完整镜头逻辑、交互出口与轻量几何的**视觉演示版**，不能声称是实景重建。
