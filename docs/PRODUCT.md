# 漓江·移笔游目 产品需求 v0.2

## 目标

创作「可以进入的漓江青绿山水长卷」，观众在原画中游历。首要目标是**忠实展示已制作的独立清昼、夕照、入夜全景**，再用人物和简约交互增加沉浸感，不能让技术方案降低画质。

## 视觉与交互

- 首页：高画质三时辰全景作主题背景，独立时辰选择；「入画启程」「山水漫游」两入口。
- 漫游画卷：PixiJS 保持三幅 2172×724 原比例画幅；时辰独立切换、相机横移和缩放、四景对应原稿地标位置。
- 人物：壮族服饰人物五张原始姿态无损展示；键盘/触控移动；「对山歌」动作只作为关键姿态预览。
- 景点：象鼻山、日月双塔、阳桥、玻璃桥按原画相对空间顺序（艺术化拼接，不当作地图）。
- 动效：轻微水面圆波，移动镜头、背景淡入；减少动态效果用户得到静态替代。
- 设备：宽屏与手机可操作，首屏图片体积较大需要可见 loading。

## P0 验收

1. 三幅背景独立切换，色彩、塔灯与倒影对应原稿，而不是 Tint。
2. 无损原像素输出，画面不按窗口尺寸任意拉伸。
3. 横向漫游、触控和键盘、四处导航、五姿态正确调度。
4. GitHub Pages 用 Actions 发布 Vite 构建产物，所有图片和脚本 HTTP 可访问。
5. 错误、初始加载、移动端可点击、reduce motion 适配。

## P1

前景桥栏遮挡、步行序列图集、正式音频字幕和地形高度美术复核；先完善最好的一个场景，不为了数量牺牲品质。

## 非目标

不做真实地理路线、不做账号后端、不做真实音乐自动播放、不宣称已拥有完整的行走动画。

## 时辰叙事交互增量（P1/P2）

清晨：点击岸边渔人，问象鼻山方向或竹筏启程（P0 可操作文字脚本，P1 完整整理竹筏动画）。正午：鸬鹚捕鱼、岸边买鱼（P0 水纹/模拟问价，P1 完整捕鱼和交易状态机）。入夜：分段灯光点亮、岸边/船上观赏方式、音乐驱动倒影、对山歌、无人机概念演出（P0 可开关表现与静音节拍预览，P2 正式分层灯光/船/音乐/编队）。夕照保留独立完整美术与自由漫游。完整验收和素材依赖参见 [INTERACTION_PLAN.md](INTERACTION_PLAN.md)。

除现有三张独立画卷外，清晨和正午暂共用白昼原画，不能虚构第四幅已绘制画作；除已有姿态外的 NPC 动画必须如实标注待制作。
