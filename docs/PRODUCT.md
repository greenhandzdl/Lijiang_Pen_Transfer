# 产品需求 — 漓江·移笔游目

## 愿景与受众
让观众在青绿山水画卷中以壮族服饰角色缓慢游历，感受漓江周边的山水与地方文化。受众包括艺术与非遗文化爱好者、手机网页访客、展览观众。

## 体验原则
1. **画面优先**：保留宣纸质感、低饱和青绿配色、留白和传统长卷的观看节奏。
2. **入画即玩**：无登录、可跳过引导、进入即见人物和景观。
3. **少而精**：每个景点一个独特互动，避免任务列表/积分体系。
4. **跨设备**：桌面键鼠与手机触摸的主流程都能完成。
5. **尊重文化**：山歌和民俗内容由可追溯文本/音频提供；演示暂用示意性文案。

## 路线
- 首页：长卷预览，左侧标题与「入画启程 / 山水漫游」，右上角模式切换。
- 入画启程：进入第一景，角色能左右行走，抵达热点后触发卡片和姿态演出。
- 山水漫游：可拖拽/缩放画面，四节点自由定位；随时回首页。
- 四个艺术化节点：象鼻山、日月双塔、阳桥、玻璃桥。画卷内位置为**艺术编排**，不代表地理测绘。
- 时辰切换：日间 / 黄昏 / 夜晚色调（Demo 为调色版，不代表完整独立夜景美术）。
- 对山歌：切换演出姿态、字幕、可退出；正式版由真实歌曲与演出素材替换。

| ID | 需求 | 验收标准 |
|---|---|---|
| P0-01 | 首页 | 手机/桌面展示画面、标题与双入口 |
| P0-02 | 初始化 | 能在仓库 Pages 子路径正常载入全部资源 |
| P0-03 | 漫游 | 拖动、滚轮/双指缩放、箭头/触控移动与位置跳转有效 |
| P0-04 | 人物 | 关键姿态切换、脚底锚点、一致世界高度 |
| P0-05 | 景点 | 四热点可以导航与关闭说明 |
| P0-06 | 时辰 | 三种切换状态可见且不丢失漫游位置 |
| P0-07 | 降级 | 减少动态效果、异常图片有提示、无音频自动播放 |
| P0-08 | 发布 | main push 后 Actions 构建并发布 Pages |

## 后续 P1
分层场景（远山/中景/岸线/人物/前景）、路径高度、6–8 帧动画、人物事件状态机、动态水面、游船、字幕/音效系统、图集按需加载。

## P2
民族文化编辑审核流程、完整山歌互动、人物/NPC、雨/风/节令、游记与画稿导出、可访问性专项优化。

## 非目标
首版不做真实旅行地图、不做多用户/登录、不做复杂物理、不做收费、不宣称史料级地理和服饰考证。
