# 项目路线图

## M0（当前提交）— 工程与规范
- [x] 仓库文档、.gitignore、AGENTS.md、素材/架构/测试规范
- [x] PixiJS 8 / TypeScript / Vite / React 初版工程代码
- [x] 样图浏览与交互垂直切片（低清素材预览）
- [x] GitHub Actions TypeScript 检查与 Vite 构建通过
- [ ] 需要仓库管理员在 Settings → Pages 中设置 Source: GitHub Actions，再确认发布

## M1 — 第一景精修（2–3 周）
- [ ] 首页视觉对齐原 UI 设计，不直接把带字图片当 UI
- [ ] 分层象鼻山场景、岸线、正确人物脚底
- [ ] 左右行动画：6–8 帧完整、方向过渡与暂停
- [ ] 触控/键鼠完整交互，3 档质量，减少动态效果
- [ ] 页面首次加载、FPS、画面截图基线与回归

## M2 — 四景贯通（3–5 周）
- [ ] 日月双塔/阳桥/玻璃桥多张独立分层高清画面
- [ ] 艺术化连续路线，明确与地理真实路线的区分
- [ ] 层间遮挡和真实桥面高度
- [ ] 昼/暮/夜时间系统，按需环境特效
- [ ] 对山歌单事件完整状态机/字幕，可选择静音

## M3 — 文化完整度与正式版
- [ ] 文化专家或资料核实（民歌、服饰、故事）
- [ ] 授权的原声录制和字幕
- [ ] 画稿导出、场景收藏、首屏性能专项
- [ ] 辅助功能、多设备验收、版权与安全核验

## 原则
每个里程碑都有一段可以连续体验的版本。功能不以数量为指标，先保证画面、脚底、遮挡、动画和性能，再扩展内容。
